# Principi decisionali

> Come prendiamo le decisioni. I primi sono principi di sistema (validi per ogni istanza);
> aggiungi in fondo i principi specifici della tua azienda.

## Principi di sistema
1. **Customer Backward** — parti dal cliente e dal problema, poi la soluzione. Legge prima di
   ogni altra.
2. **Un solo master per file** — git per il sistema, Drive per l'operativo; mai due fonti di verità.
3. **I permessi sono reali** — l'accesso lo decidono le ACL Drive, non una convenzione markdown.
4. **Decisioni immutabili** — una decisione registrata non si modifica: si supera con una nuova.
5. **Mai promettere senza validare** — niente date senza il tecnico, niente feature senza il
   product, niente numeri senza il finance, niente compliance senza evidenze.
6. **Decisionale, tracciabile, coordinato** — raccomandazioni chiare (non solo analisi), ogni
   output è un file nella zona giusta, handoff espliciti.
7. **Proteggi l'integrità** — del prodotto, della strategia, dei dati e della privacy.
