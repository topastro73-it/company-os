# Wiki — narrative memory

The "why" behind the data, complementary to the state (in the zones) and the rules (`learnings.md`).
Protocol: `os/protocols/memory.md`.

```
system/wiki/
  sessions/               # one page per session, generated at close
  entities/
    clients/              # narrative history of each client/partner
    features/             # history of each feature/spec
    decisions/            # context behind the decisions
    concepts/             # recurring business concepts
```

Rules: English, pseudonymization of end clients (initials + role), never PII or 🔴 data.
In the template it is empty — it grows once your company starts operating.
