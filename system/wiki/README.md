# Wiki — memoria narrativa

Il "perché" dietro i dati, complementare allo stato (nelle zone) e alle regole (`learnings.md`).
Protocollo: `os/protocols/memory.md`.

```
system/wiki/
  sessions/               # una pagina per sessione, generata al close
  entities/
    clients/              # storia narrativa di ogni cliente/partner
    features/             # storia di ogni feature/spec
    decisions/            # contesto dietro le decisioni
    concepts/             # concetti ricorrenti del business
```

Regole: inglese, pseudonimizzazione dei clienti finali (iniziali + ruolo), mai PII o dati 🔴.
Nel template è vuota — cresce quando la tua azienda inizia a operare.
